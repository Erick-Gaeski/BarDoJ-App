# ContaBar UI Design Skill

**Objetivo** – melhorar a interface onde os garçons e a equipe de padaria operam.

**Diretrizes**
1. Interface **simples**, **não maximalista** – foco no fluxo de trabalho.
2. **Fácil de operar** durante o serviço – toques grandes, texto legível.
3. **Aparência de sistema** – uso de paleta cromática quente: fundo creme, verde escuro, âmbar, pequenos detalhes terracota; texto em grafite (negro escuro).
4. **Acessibilidade** – contraste mínimo 4.5:1, foco teclado, textos grandes.
5. **Controles adequados para toque** – botões >48 px, espaçamento 1 rem.

*Neste projeto a skill só informa a diretriz; nenhuma alteração automática é realizada.*
